# better-dsh

[English](README.md) | 简体中文

基于 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）`0.2.1-rc.3` 开发。

## 改了什么

### 目录链接能直接打开了

原来在聊天里点一个目录路径（或者 `present` 一个目录），右边栏只会显示一句「该路径不是普通文件，没有可显示的内容」，右上角也没有任何按钮——预览头部要等 `stat` 拿到文件信息才渲染，目录走不到那一步。

装了这个插件之后：

- 点目录会打开一个文件夹页，能看到文件列表（文件夹排前面）和文件大小，可以返回上一级、刷新，点文件还是用原来的预览打开。
- 点文件的行为没变。探测失败、超时或者拿不到 Remote 的时候，都按原来的逻辑走，细节写在 [docs/folder-browser.md](docs/folder-browser.md)。
- 右边栏「+」里加了一张「浏览文件夹」卡片，可以从工作区根目录开始翻。

### 任务中心

会话在左栏、后台任务在会话头、定时任务在「自动化任务」页、审批在弹窗里。任务中心把这些收进右侧边栏的一个 tab：

- **需要你**：审批、计划确认、提问、已完成未查看的会话，按紧急度排序。
- **正在运行**：正在跑的会话和后台任务，带任务数和最近活动时间。
- **已排期**：活跃定时任务，按下次触发时间排序。
- 点任意一行跳到对应会话；顶部三个数字是运行中 / 待处理 / 已排期。

读取 Session、status、jobs、schedule 的既有客户端面，服务缺失时降级为空列表，不影响文件夹页。当前是只读 MVP：刷新和跳转已通，停任务、批准、立即执行排期还没接。

### 字体与字号

这个构建的设置页里没有「更多字体设置」，所以插件在设置 → 通用里加了一块面板：

- 界面、代码、终端三种字体，以及各自字号（10–22、10–16、10–20 px）。
- 输入框留空恢复默认字体；多个字体用逗号分隔。
- 「恢复默认」清空三个字体并恢复 14 / 11 / 13 px。
- 写入 DSH 自己的 `ui-theme` 设置，持久化并即时生效。

## 安装

在 **Plugins** 页面填入：

```
git+https://github.com/lizyoko9/lizyoko-better-dsh
```

或者选择本地克隆目录安装。没有构建步骤，`client.js` 就是最终产物。

## 兼容性

在 DSH `0.2.1-rc.3` 上验证（首次开发针对 `0.2.1-rc.2`）。如果后续版本改了 tab 类型注册表、Remote 命名空间或 `settings.general.item` 槽位，对应功能可能加载失败；Console 里的日志带 `better-dsh:` 前缀。

插件只改 Web 端 UI：不注册工具、不写会话事件、不改变模型输入。
